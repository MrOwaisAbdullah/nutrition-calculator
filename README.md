# Nutrition & Macro Calculator

A clean PHP application designed to calculate personalized daily calorie targets, Basal Metabolic Rate (BMR), Total Daily Energy Expenditure (TDEE), and macronutrient splits (proteins, carbs, fats).

## 🥗 Features
- Harris-Benedict & Mifflin-St Jeor formula calculation.
- Tailored calorie targets for weight loss, maintenance, or muscle gain.
- Clean and responsive input interface.

## 🛠️ Tech Stack
- **Backend**: PHP 8.x
- **Frontend**: HTML5, CSS3
